# Reporting a security issue

For anyone who has found a vulnerability. Covers where to send it.

**Do not open a public issue, discussion, or pull request for a security
problem.** Report it privately through GitHub's private vulnerability
reporting: the **Security** tab of the repository, then **Report a
vulnerability**.

The full policy — what to include, what response times to expect, the
disclosure window, and what is in scope — is in
[SECURITY.md](../../SECURITY.md) at the repository root.
